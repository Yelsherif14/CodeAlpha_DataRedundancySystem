# Data Redundancy Removal System

A simple Flask-based system designed to detect and prevent duplicate user data before storing it in a SQLite database.

## Features

- Add unique user data
- Validate user input
- Validate email format
- Prevent duplicate email addresses
- Store data in SQLite database
- Automated testing using pytest

## Technologies Used

- Python
- Flask
- SQLite
- Pytest
- HTML/CSS
- Git & GitHub
